종자기능사 실기
D-1 「오늘 3시간 + 내일 2시간」 70점 암기 작전

시험 직전의 원칙
지금부터 새로운 책을 처음부터 읽지 않는다.
어려운 내용을 이해하려고 오래 붙잡지 않는다.
「문제 → 핵심어 → 짧은 답」을 반복해서 입으로 말하고 손으로 써본다.

1. 먼저 알아야 할 시험의 성격

현재 종자기능사 실기는 필답형이다.
실기 합격기준은 100점 만점에 60점 이상이다.
따라서 70점을 목표로 한다면 모든 내용을 완벽하게 아는 것보다 반복 출제되는 핵심 주제에서 확실하게 점수를 확보하는 전략이 좋다.

최근 2026년판 수험서들의 실기 구성과 2021~2025년 필답형 기출 수록 범위를 비교하면 다음 영역이 계속 핵심으로 다뤄진다.

우선순위 영역 오늘 공부 내일 복습
★★★★★ 종자검사 순도·활력·발아 반드시 재암기
★★★★★ 육묘·파종 상토소독·터널·볍씨·미세종자 반드시 재암기
★★★★★ 접붙이기 오이·사과·선인장·장미 사진/용어 연상
★★★★☆ 종자·묘목·병해충 감별 대표 특징 암기 빠른 회상
★★★★☆ 구근 번식 방법과 용어 짧게 복습
★★★☆☆ 조직배양 하이포넥스 배지 순서만 암기

3. 오늘 반드시 외울 것 ① — 종자검사

암기 문장: 「순도 = 깨끗한가 / 발아 = 싹이 트는가 / 활력 = 힘차게 트는가」

① 순도검사

순도는 검사 대상 종자 중에서 정상적인 해당 작물의 종자가 차지하는 비율을 보는 것이다.

순도검사 핵심
「정상종자 + 이물 + 다른 종자」를 구분한다.

순도(%) = 순수종자 중량 ÷ 시료 전체 중량 × 100

② 발아검사

발아율은 주어진 조건에서 종자가 정상적으로 발아한 비율이다.

발아율(%) = 정상 발아 종자 수 ÷ 시험 종자 수 × 100

발아율 문제를 보면
「정상적으로 싹이 난 개수 / 전체 개수 × 100」

③ 활력검사

활력은 단순히 발아할 수 있는지를 넘어 빠르고 균일하게 발아하고 생장할 수 있는 종자의 능력으로 기억한다.

시험용 구별
순도 → 「섞여 있는가?」
발아율 → 「싹이 나는가?」
활력 → 「힘차고 빠르게 자라는가?」

4. 오늘 반드시 외울 것 ② — 육묘·파종

상토 소독

암기: 「상토 소독 = 병원균·잡초·해충 제거 → 건전한 묘 생산」

상토 소독의 목적은 육묘에 방해가 되는 병원균, 해충, 잡초 종자 등을 제거하여 건전한 묘를 생산하는 것이다.

터널 재배

암기: 「터널 = 보온 + 보습 + 보호」

터널은 어린 작물을 외부의 저온·바람 등으로부터 보호하고 생육에 알맞은 환경을 만들어 주는 시설로 기억한다.

볍씨 파종

순서형 문제 대비
종자 준비 → 파종 → 복토/관리 → 발아·육묘 관리

세부 수치가 생각나지 않을 때는 엉뚱한 숫자를 쓰지 말고 자신이 확실하게 외운 핵심 용어를 먼저 적는 것이 중요하다.

미세종자

미세종자 = 작고 가벼움 → 고르게 뿌리기 어려움 → 균일 파종이 중요

미세종자는 종자가 작기 때문에 균일하게 파종하는 것이 핵심이다. 따라서 파종량과 파종 깊이를 지나치게 하지 않는 것이 중요하다.

5. 오늘 반드시 외울 것 ③ — 접붙이기

이것은 그냥 통째로 외운다.

오이 → 맞접
사과 → 깎기접
왜성사과 → 녹지접
선인장 → 안장접
장미 → 눈접

작물 접목법 암기 연결
오이 맞접 오이 = 맞접
사과 깎기접 사과 = 깎기
왜성사과 녹지접 왜성 = 녹지
선인장 안장접 선인장 = 안장
장미 눈접 장미 = 눈
입으로 10번 말하기:
“오이 맞접, 사과 깎기접, 왜성사과 녹지접, 선인장 안장접, 장미 눈접.”

6. 오늘 반드시 외울 것 ④ — 구근 번식

구근 분구 번식은 하나의 구근에서 새로운 개체가 생길 수 있도록 구근을 나누어 번식시키는 방법으로 기억한다.

시험에서는 긴 설명보다 「구근 → 분구 → 새로운 개체」라는 흐름을 먼저 기억한다.

암기어: 「구근은 나눠서 늘린다」

7. 오늘 반드시 외울 것 ⑤ — 조직배양

핵심 단어 하나: 하이포넥스 배지

2026년판 실기 대비서에서도 조직배양 항목으로 하이포넥스 배지 만들기를 별도 항목으로 다루고 있다.

시험장에서 조직배양 문제가 나오면
무균상태 → 배지 → 배양 → 증식·생장 의 흐름을 떠올린다.

8. 감별 문제는 이렇게 공부한다

감별 문제를 전부 외우려고 하면 3시간으로는 부족하다. 따라서 오늘은 사진을 보고 이름 → 특징 1개만 연결한다.

감별 종류 암기법
종자 감별 모양·크기·색·표면 특징 1개
묘목 감별 잎·줄기·형태 특징 1개
병해충 감별 피해 증상 1개
절대 하지 말 것
이름 30개를 무작정 외우기 ×

할 것
「사진 → 이름 → 특징 한마디」로 연결하기 ○

  9. 오이의 접목법은?
  10. 사과의 접목법은?
  11. 왜성사과의 접목법은?

  13. 장미의 접목법은?

11. 시험 직전 10분 초압축 암기표

① 종자검사

순도 = 깨끗한 종자의 비율
발아 = 정상적으로 싹이 트는 비율
활력 = 빠르고 균일하게 생장하는 능력

② 계산

순도(%) = 순수종자 중량 ÷ 전체 시료 중량 × 100
발아율(%) = 정상 발아 종자 수 ÷ 전체 종자 수 × 100

③ 육묘

상토소독 = 병원균·해충·잡초 등 제거
터널 = 보온·보습·보호
미세종자 = 균일 파종이 중요

④ 접목

오이 = 맞접
사과 = 깎기접
왜성사과 = 녹지접
선인장 = 안장접
장미 = 눈접

⑤ 번식

구근 = 분구
조직배양 = 하이포넥스 배지

12. 70점 목표를 위한 답안 작성법

답을 완벽한 문장으로 쓰려고 하지 않는다.

예를 들어 “상토 소독의 목적은 무엇인가?”라고 나오면

병원균 제거 / 해충 제거 / 잡초 제거 / 건전한 묘 생산

처럼 채점자가 찾을 만한 핵심어를 넣는다.

모르는 문제를 만났을 때

  1. 문제의 핵심 단어에 밑줄을 긋는다.
  2. 종자검사 / 육묘 / 파종 / 번식 / 육종 중 어느 분야인지 판단한다.
  3. 관련된 핵심어를 먼저 쓴다.
  4. 빈칸으로 내지 않는다.
특히 숫자를 확실히 모르면 추측해서 여러 숫자를 쓰지 않는다.
확실하게 아는 정의, 목적, 순서, 용어를 먼저 적는다.

13. 60대 암기력이 약할 때 가장 효과적인 방법

① 눈으로 3번 읽지 말고 입으로 3번 말하기

“오이 맞접, 사과 깎기접...”처럼 소리 내어 말한다.

② 한 번에 5개만 외우기

오늘의 핵심은 다음 5개다.

오이-맞접
사과-깎기접
왜성사과-녹지접
선인장-안장접
장미-눈접

③ 10분 뒤 다시 테스트

읽고 끝내지 말고 책을 덮고 바로 말한다. 기억이 안 나는 것이 정상이다. 기억이 안 나는 순간 다시 떠올리는 과정이 암기다.

④ 손으로 한 번 써보기

특히 계산식과 접목법은 직접 한 번 써본다.

15. 마지막으로 기억할 한 문장

「전부 외우려고 하지 말고,
종자검사 + 육묘 + 접목을 확실히 잡고,
나머지는 핵심어로 점수를 보탠다.」
본 학습안은 큐넷의 현행 종자기능사 시험정보와 2026년판 실기 대비서에서 확인되는 실기 핵심 구성 및 2021~2025년 필답형 기출 수록 범위를 바탕으로 D-1 단기 암기용으로 재구성한 것이다. 실제 시험문제의 출제 여부나 정확한 배점·문항별 출현을 보장하는 '적중 예상문제'가 아니므로, 시험장에서는 실제 문제의 요구사항을 우선한다.
