경기도 화성시 남양읍 신외리 146-1 · 755㎡ 학교 과수원.
100여 종의 과수·채소·산채를 다섯 구역에서 기릅니다.

핵심은 「맞춤」 입니다.
  · 심겨진 작물에 맞춰   (1년생·다년생·과수를 다르게 헤아림)
  · 우리 밭 흙에 맞춰     (토양검정 처방, 전국 표준값 아님)
  · 가진 비료·농약에 맞춰 (창고를 먼저 보고, 모자란 것만 알려줌)
  · 농부에 맞춰          (폰으로 밭에서, 주말농부 모드)

폰(아이폰 12 Pro, 390px)으로 밭에서 씁니다.
자료는 구글 시트, 처방은 농촌진흥청·기상청 공공 API.

│  4. ⚠️ 함정 여섯 — 이것만은 꼭                              │
└───────────────────────────────────────────────────────────┘

① 작물코드가 세 가지입니다

   같은 「배」인데 API마다 다릅니다.
     soilCropAll (표준사용량)  09011
     expCropCode (체험)        00066
     soilCropCode (재배기간)   00066  ← 체험과 같은 체계

   ❌ soilCropAll 을 「작물코드 목록 API」로 갱신하지 마세요.
      한 번 그렇게 했다가 95종이 못 쓰게 되어 되돌렸습니다.
      작물코드는 흙토람 웹 화면에서만 받습니다.


② growRecords 의 열이 둘입니다

     eventType (4열)  ← 화면이 읽음
     type      (12열) ← 옛 열

   저장할 때 둘 다 보내야 합니다.
   한쪽만 쓰면 저장은 되는데 화면에 안 나옵니다.


③ 열 위치를 고정하지 마세요

   시트에 열이 늘거나 순서가 바뀝니다. 머리글로 찾으세요.
     var hdr = _gpHeaders();
     var ci = hdr.indexOf('fertCd');


④ 흙토람 API 는 하루 100회입니다

   넘으면 HTTP 429. fertStdCache 시트에 저장해 재사용합니다.


⑤ 본문 글자가 px 로 428곳 박혀 있습니다

   body { font-size } 로는 안 커집니다.
   글자 크기는 zoom 으로 처리했습니다.


⑥ 농약 메모의 형식이 제각각입니다

   배(검은무늬병,발병 초부터,1000배 -,수확7일전,5회,Ⅳ,Ⅰ급)
   감(단감 포함)(탄저병,...)          ← 괄호가 이름 안에
   감(일년생잡초,...,- 500㎖/10a,...)  ← 희석배수 대신 살포량

   쉼표 자리로 세지 말고 「숫자+배」 「숫자+회」 로 찾으세요.

문법 검사 (필수)
  node -e "
  const fs=require('fs');const t=fs.readFileSync('gi1.html','utf8');
  const b=[...t.matchAll(/<script(?![^>]*\ssrc=)[^>]*>([\s\S]*?)<\/script>/g)]
    .map(m=>m[1]);
  fs.writeFileSync('/tmp/z.js', b.join('\n;\n'));
  " && node --check /tmp/z.js && echo "JS OK"
